My name is Subhransu Nayak, and I am currently a Class 12 student from Odisha, India. Although my board exams are not yet completed, my journey into technology started much earlier.

Back in Class 9, I began learning Linux out of curiosity, followed by Python and Java basics. Coming from a small town with limited resources and no proper computer lab, I relied mostly on self-learning, experimentation, and building projects.

I was always curious about how platforms like Netflix stream massive files, how Amazon handles dynamic pricing, and how modern web applications scale to millions of users. Instead of only consuming tutorials, I focused on learning by building.

Over the years, I have developed several projects, including:

* A platform for booking plumbers within 30 minutes
* A YouTube comment automation and auto-reply tool
* A gamified trading platform
* A creator toolkit platform inspired by VidIQ
* An AI tutor platform for students
